## Personal Portfolio 

A modern, responsive portfolio website showcasing my projects, skills, and professional experience.

### Features

- **Responsive Design** - Seamless experience across desktop, tablet, and mobile devices
- **Modern UI/UX** - Clean, professional design with smooth animations and transitions
- **Dynamic Contact Form** - Integrated with Web3Forms for reliable message delivery
- **Project Showcase** - Interactive gallery highlighting key projects and achievements
- **Skills Section** - Comprehensive display of technical competencies
- **Performance Optimized** - Fast loading times and smooth scrolling
- **Accessibility Focused** - WCAG compliant with semantic HTML

### Built With

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with custom properties and animations
- **JavaScript** - JS for interactivity
- **Web3Forms** - Backend form handling
- **Line Awesome Icons** - Elegant iconography
- **Google Fonts** - Custom typography
